# YardNav Kyiv

Прототип пешеходного навигатора, который предпочитает:

- проходы через дворы;
- внутриквартальные пешеходные дорожки;
- тропы и грунтовые дороги;
- тихие жилые улицы;

и штрафует маршруты вдоль дорог общего пользования, особенно крупных.

В режиме `Горный велосипед 10+ км/ч` навигатор:

- исключает лестницы без `ramp:bicycle=yes`;
- предпочитает дворы, грунтовки, треки и велодорожки;
- штрафует поднятые бордюры, ворота и другие барьеры;
- оценивает скорость по типу пути, покрытию и препятствиям;
- показывает, достигается ли расчетная средняя скорость 10 км/ч.

Режим `Экспериментальный по тропам` сильнее предпочитает линии OSM
`path`, `footway`, `track` и дворовые проходы. Скорость в нем не влияет на
маршрут, а бордюры и проезжаемые барьеры штрафуются слабее. Лестницы без
велопандуса, `bicycle=no` и закрытый частный доступ по-прежнему исключаются.

В режиме `Кастомный через мои точки` первый клик задает старт, следующие клики
задают обязательные точки по порядку, а последняя точка считается финишем.
Кнопка `Построить` соединяет все участки экспериментальным профилем. Доступно
до 20 точек, последнюю можно удалить до повторного расчета.

## Почему обычного кратчайшего пути недостаточно

OpenStreetMap содержит большую часть нужных объектов, но стандартный пешеходный
роутер оптимизирует время или расстояние. YardNav добавляет каждому сегменту
виртуальную стоимость:

```text
стоимость = длина * коэффициент типа пути + фиксированные штрафы
```

Например, 100 метров по дворовому проезду могут быть дешевле 70 метров по
тротуару вдоль магистрали. Дороги не запрещаются полностью, чтобы маршрут
оставался достижимым для адресов, у которых нет другого входа.

## Структура

- `src/yardnav/profile.py` — классификация OSM-сегментов и расчет стоимости.
- `src/yardnav/routing.py` — A* по подготовленному графу.
- `src/yardnav/osm.py` — импорт пешеходного графа из OSM XML.
- `src/yardnav/app.py` — HTTP API и локальный веб-сервер.
- `data/kyiv/` — плитки актуального OSM-графа Киева.
- `tests/` — тесты ключевого поведения профиля и роутера.
- `docs/architecture.md` — план получения данных Киева и построения продукта.

## Запуск

Требуется Python 3.11+. Из корня проекта:

```bash
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -e .
yardnav
```

Открыть `http://127.0.0.1:8000`, затем выбрать две точки на карте. По умолчанию
загружается OSM-граф всего Киева. Первый запуск занимает около 30-45 секунд,
пока XML-плитки преобразуются в граф.

Картографические данные: © участники OpenStreetMap, лицензия ODbL.

## Геолокация

Кнопка `Моё местоположение` выбирает текущую позицию как старт. Непрерывное
отслеживание показывает точность GPS, прогресс, оставшееся расстояние и
отклонение от маршрута. Координаты обрабатываются в браузере и не сохраняются.

Кнопка `Не выключать экран` использует Screen Wake Lock API. При включении
GPS-отслеживания подсветка активируется автоматически и восстанавливается после
возврата в приложение. Функция требует HTTPS или `localhost`, зависит от
поддержки браузера и может отключаться системой в режиме энергосбережения.

На мобильном устройстве сайт можно добавить на домашний экран. Он поддерживает
standalone-режим без адресной строки через web app manifest.

На Mac геолокация работает через `http://localhost:8000`. Для открытия с iPhone
сервер должен быть доступен в локальной сети, но Safari разрешает геолокацию
только в защищенном контексте HTTPS. Для реального использования на iPhone
нужен HTTPS-домен или локальный сертификат, которому доверяет устройство.

Можно запустить сервер без установки проекта, если Flask уже установлен:

```bash
PYTHONPATH=src python3 -m yardnav.app
```

Другой OSM XML-файл передается явно:

```bash
yardnav --osm /path/to/kyiv.osm
```

Формат `.pbf` текущий импортер еще не поддерживает.

## Деплой на Seenode

Проект подготовлен к запуску через Gunicorn:

```bash
pip install -r requirements.txt
./start.sh
```

Команда запуска в Seenode:

```bash
./start.sh
```

Приложение слушает `0.0.0.0` и использует переменную `PORT`, по умолчанию
`8000`. Health check:

```text
/api/health
```

Для графа всего Киева обязательно оставить один worker:

```text
WEB_CONCURRENCY=1
```

Холодный старт занимает около минуты. Каталог `data/kyiv/` размером около
83 МБ должен быть включен в деплой. HTTPS на домене Seenode нужен для
геолокации и функции постоянной подсветки мобильного экрана.

Один загруженный worker использует примерно 730-800 МБ RAM. Минимально нужен
инстанс с 1 ГБ памяти, рекомендуется 2 ГБ для запаса под запросы, обновления и
служебные процессы платформы. Не добавляйте второй Gunicorn worker.

## API

```bash
curl -X POST http://127.0.0.1:8000/api/route \
  -H 'Content-Type: application/json' \
  -d '{
    "start_lat": 50.448,
    "start_lon": 30.505,
    "goal_lat": 50.452,
    "goal_lon": 30.514
  }'
```

Ответ — GeoJSON `LineString` с длиной, ожидаемым временем и координатами
привязанных к графу точек.

```bash
python3 -m unittest discover -s tests -v
```
